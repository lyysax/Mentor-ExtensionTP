# Mentor Extension

Une extension de navigateur proposant des outils pour accompagner les mentors au quotidien.

La version actuelle propose un compteur pour les « eh ».

## Installation

1. Télécharge le projet depuis GitHub avec **Code → Download ZIP**.
2. Décompresse le fichier ZIP sur ton ordinateur.
3. Ouvre la page des extensions de ton navigateur
4. Active le **Mode développeur**.
5. Clique sur **Charger l’extension non empaquetée** (_Load unpacked_).
6. Sélectionne le dossier du projet contenant le fichier `manifest.json`.
7. Vérifie que l’extension est activée.

## Utilisation

1. Ouvre le menu des extensions dans la barre d’outils du navigateur.
2. Clique sur **Mentor Extension** pour ouvrir son interface.
3. Utilise les compteurs.
